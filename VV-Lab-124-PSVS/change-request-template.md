# Change Request Template

| Field | Details |
|---|---|
| Change Request ID | CR-001 |
| Artifact | Name or path of the affected requirement, model, operation, or document |
| Reason | Explanation of the defect, ambiguity, or requested change |
| Impact | Expected effect on requirements, design, implementation, verification, and related artifacts |
| Approver | Name or role of the authorized person approving the change |

## Change Description

**Current behavior or requirement:**  
Describe the existing behavior or requirement.

**Proposed change:**  
Describe the requested modification.

**Verification required:**  
Specify the tests, checks, or proofs needed to validate the change.

**Status:** Proposed / Under Review / Approved / Rejected / Implemented
