# VV-Lab-124-PSVS

**Course:** Practical Software Verification and Validation
**Project:** Polar Seed Vault System  

## 1. Project Overview

The Polar Seed Vault System stores sealed crop-seed boxes belonging to registered institutions, including gene banks, universities, and governments. The vault acts as a custodian and does not own the stored boxes.

The system manages depositors, seed boxes, freezer chambers, withdrawals, temperature monitoring, seed viability, maintenance, and audit records.

## 2. Repository Structure
- `requirements/` — Functional and non-functional requirements.
- `defect-logs/` — Identified defects, inconsistencies, and corrective actions.
- `abstractions/` — Abstract system definitions and assumptions.
- `models/` — Formal and behavioral system models.
- `operations/` — System operations and state transitions.
- `constraints/` — Invariants and system constraints.
- `proofs/` — Verification obligations and proof results.
- `reports/` — Verification reports and submission evidence.
